# 图绎（Figlyph）

无构建依赖的浏览器图片编辑器。入口 `/editor/`（`editor/index.html`）加载 `editor/editor.css` 和 `editor/editor.js`，复用仓库已有字体与风景图片；基础编辑不依赖外部 API；可选 AI 文字助手通过用户自行配置的 OpenAI 兼容接口运行。

## 本地运行

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory /workspace/clyfort.github.io
```

在浏览器访问服务器的 `/editor/` 路径。博客首页保持原样。需要使用 HTTP 服务加载 ES 模块。

## 功能

- 图形：选择矩形、圆角矩形、圆形、三角形、直线、块状箭头或线条箭头工具后，在画布按住鼠标拖动确定位置与尺寸；Shift 等比绘制或限定线条角度，Esc 取消。默认黑色空心，可在属性面板启用填充；箭头有块状和「直线 + V 形箭头」两种。支持反向拖动和斜向箭头；填充、渐变、描边、圆角与阴影。
- 自由画笔：颜色、粗细，可作为独立图层移动与缩放。
- 文字：点击添加文字或按 T 后，在画布单击确定位置并开始输入，Esc 可取消放置；清空全部文字（或仅剩空白）并确认后自动删除文本框，支持撤销。在选择工具下双击画布文字框内任意位置即可直接编辑，点击框外或按 Ctrl/⌘+Enter 完成；高度根据实际字形和换行自动计算，角点拖动等比缩放文字；字体、字号、字重、斜体、下划线、删除线、行距、字距、段距、对齐；选中右侧文字内容中的片段可单独设置样式。
- 文字样式记忆：普通“添加文字”沿用最近使用的字体、字号、粗体、斜体、下划线、删除线、颜色、行距、字距、段距和对齐方式，在当前浏览器中刷新后仍保留；大标题、副标题、正文预设明确采用各自的字号和粗体设置，其他样式继续沿用。
- 文字框宽度：新建文字框默认按文字实际宽度自动增长或缩小，显式换行按最长一行决定宽度；更改字体、字号或局部样式会同步更新。手动修改 W 或拖动角点缩放后转为固定宽度并自动换行，可勾选“随文字自动调整宽度”恢复。保存/重开与撤销保留此模式；旧项目中没有宽度模式标记的文字框保留既有尺寸。
- 混合格式编辑：画布上的文字编辑器支持同一段文字中的不同字体、字号、粗体、颜色及装饰，选中或编辑时继续显示原样；支持换行、纯文本粘贴、中文输入及编辑中的撤销与重做。
- 局部文字样式：在画布文字编辑框或右侧文字内容中选中片段后，直接调整字体、字号、颜色、粗体等设置；切换设置时保持选区，并在画布持续高亮该片段；字体和字号控件保持焦点，继续修改时仍只作用于该片段。编辑内容后失焦不会再次清空选区，插入或删除文字会保留未改动字符的局部样式。
- AI 文案助手：润色、精简、生成 3 条海报标题。可处理画布选中的文字、整个文本框或手动输入的文字；先预览和编辑，再替换原文选区或新增文字图层；支持撤销与重做。
- 字体导入：TTF、OTF、WOFF、WOFF2。字体内嵌保存到项目。
- 图片：文件上传、拖放、粘贴，取景裁切、翻转、亮度、对比度与饱和度。导入时保留原始像素宽高；空画布直接匹配原图尺寸，已有作品按需扩展画布并保留原图层，预览缩放不影响导出分辨率。
- 图片滤镜：选中图片后，在属性面板查看原图、鲜活、柔光、淡雅、电影、黑白、明亮和浓郁 8 个缩略图预览；一键应用后仍可微调亮度、对比度与饱和度。滤镜直接设置这三个数值，重复切换不叠加；「原图」恢复色彩调整，保留裁切、翻转、尺寸和其他外观。支持撤销、重做、项目保存和导出，锁定图片须先解锁。
- 图片布局：一键完整放入、铺满画布或恢复原始像素尺寸；保持图像比例并居中，重置旋转和取景，保留滤镜、翻转和其他外观。
- 对象：拖动、角点缩放、旋转、画布对齐；Shift + 拖动角点保持比例。
- 对齐与分布：6 种边缘/中心对齐，单选对齐画布，多选可选择以所选元素或画布为参考。3 个以上可编辑元素可水平或垂直等间距分布，按旋转后的边界计算并固定两端；锁定或隐藏的图层保持原位。
- 多选：Ctrl/⌘ + A 选中所有可见且未锁定的元素；M 框选工具可从任意位置拖出选框，默认选中与框接触的元素，也可在工具栏切换为「完全包含」。选择工具也可从空白区域开始框选。Shift + 点击增减选择、Shift + 框选追加选择；所选元素可整体移动、复制、删除。文字输入框内的 Ctrl/⌘ + A 保持原生文字全选行为。
- 系统字体：提供等线、微软雅黑选项，使用设备已安装的字体，未安装时回退到内置思源黑体；Satoshi 主要用于西文。支持自行导入字体文件。
- 图层：按名称或文字内容搜索；在右侧属性面板自定义图层名，修改文字或 AI 改写后继续保留。单选或多选可前移、后移、置顶和置底，保留所选图层的相对顺序；支持显示、锁定、复制和删除。撤销与重做最多保留 60 个状态，撤销编辑后保持该图层被选中。
- 画布：自定义尺寸、预设、背景色、缩放和平移。元素面板、画布设置和区域清除面板均提供白色和黑色背景快捷选项。
- 裁切画布：按 C 或点击裁切工具，拖动选区后按 Enter 或属性面板按钮确认；支持 Shift 正方形、精确坐标尺寸与 Esc 取消。只改变画布范围，所有图层同步平移、框外图层仍保存在项目中，可撤销和重做。
- 区域清除：按 R 或点击工具栏「区域清除」，拖出矩形选区，按 Delete/Backspace（或属性面板按钮）填充为当前背景色；支持撤销、重做、项目保存和导出，背景改色时已清除的区域同步更新。V/M 仍选择和删除完整元素，输入文字时 Delete 仍编辑文字。
- 剪贴板：复制/粘贴所选可编辑图层，保留局部文字样式、自定义名称和相关字体；外部图片优先按图片粘贴，外部纯文字直接成为文字图层。输入框和画布文字编辑保持原生粘贴。
- 文件：PNG、JPG、WebP 导出，支持整个画布或仅所选可见图层；所选图层按独立边界裁切，不包含其他图层，可保留透明背景。支持原始、2 倍、半尺寸，自动限制单边 16384 px 和总面积 6400 万像素；JPG 使用画布背景色。`.figlyph` 项目文件保存/打开，兼容旧版 `.shiguang` 文件。
- 自动保存：浏览器 localStorage。存储空间不足会提示，重要作品请另存项目文件。

基础编辑在浏览器本地进行，不会把图片上传到服务器。只有点击 AI 助手的“生成结果”才会将上方原文发送到配置的接口，不发送图片、字体或其他图层。大图片、内嵌字体和长历史会占用内存；图片单文件上限 15 MB、字体 20 MB、画布单边最大 16384 像素、总面积最大 6400 万像素。导入的动画图片按静态帧绘制。

## AI 文案助手

点击左侧“AI 助手”，或选中文字后点击右侧“AI 文案改写”。在“连接设置”中选择 OpenAI、DeepSeek 或自定义服务，填写接口基础地址、模型名称和 API Key，再选择操作并生成。

- 接口需兼容 `POST /chat/completions`，并允许浏览器跨域访问；例如基础地址 `https://api.openai.com/v1`。也可填完整的 Chat Completions 地址。代理可不填密钥；生产接口须用 HTTPS，本机调试允许 localhost HTTP。
- 模型名称由你的服务决定。OpenAI 默认 `gpt-4.1-mini`，DeepSeek 默认 `deepseek-chat`，均可修改。API 调用使用该服务自己的额度，不能使用 ChatGPT/Codex 聊天订阅额度。
- 密钥仅保留在当前页面的内存中，刷新后需重新填写；不写入 localStorage、sessionStorage、项目文件或压缩包。只保存基础地址和模型；修改地址或切换服务时清空旧密钥。
- 每次最多处理 10000 个原文字符，单次输出上限为 4096 tokens。请求可停止，90 秒超时；关闭助手也会中止等待。不会自动重试或在后台连续调用。
- 结果先在可编辑的文本框中预览；新增图层会保留原稿，并沿用选区首字样式。替换时结果沿用选区首字样式，选区外的文字和局部样式保留；整段混合样式的原文建议选择新增图层保留。
- 在未提供真实 API 凭据的开发环境中，使用模拟接口验证交互、协议、异常、取消与隐私行为，不将测试结果当作真实模型改写质量的验证。

## 快捷键

`V` 选择、`M` 框选、`H` 平移、`B` 画笔、`T` 文字；空格临时平移；Ctrl/⌘ + 滚轮缩放。
Ctrl/⌘ + Z 撤销、Shift + Z 重做、D 复制图层、S 保存项目；Ctrl/⌘ + [ / ] 后移或前移，另按 Shift 可置底或置顶；方向键微调位置，Shift 加速。
